# Third-party notices

## Caddy Manager icon

`static/caddy-icon.png` is the original reference icon from [the0neand0nly001/caddymanager](https://github.com/the0neand0nly001/caddymanager), retained at its author's request. The displayed `static/rathole-icon.png` is an adapted version with rose nodes and the text **RATHOLE MANAGER**, used for the application and browser-tab icon. Its dark badge and branching mark follow the original.

The layout also takes inspiration from Caddy Manager. Rathole Manager's application and host-agent code are separate implementations.

## Rathole

[Rathole](https://github.com/rapiz1/rathole) is a separate project. Rathole Manager does not bundle or replace the Rathole binary. Install and configure a compatible Rathole server/client pair before installing the manager.

## Python dependencies

Runtime dependencies are listed in `requirements.txt` and retain their respective upstream licences.
